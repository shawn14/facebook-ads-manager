# Ad Image Assets

Place your 3 ad images in this folder with these exact names:

## Required Images:

1. **ad1_never_miss.jpg** (or .png)
   - Campaign: "Never Miss a Stock Move"
   - Message: Direct value, simple
   - Show: App notification/alert feature

2. **ad2_your_stocks.jpg** (or .png)
   - Campaign: "Your Stocks, Your Alerts"
   - Message: User control, customization
   - Show: User setting up custom alerts

3. **ad3_stop_guessing.jpg** (or .png)
   - Campaign: "Stop Guessing, Start Knowing"
   - Message: Problem → Solution
   - Show: App providing real-time data/insights

## Image Specifications:

- **Size:** 1080x1080px (square, recommended) or 1200x628px (landscape)
- **Format:** JPG or PNG
- **File size:** Under 5MB
- **Text overlay:** Minimal (Facebook limits text to 20% of image)
- **Content:**
  - Show your app in action
  - Use high-quality screenshots or mockups
  - Avoid generic stock photos
  - Make it visually appealing but simple

## Design Tips:

✅ DO:
- Use your brand colors
- Show actual app screens
- Keep backgrounds clean
- Make text readable on mobile
- Test on different devices

❌ DON'T:
- Use too much text overlay (Facebook will limit reach)
- Make images too busy or cluttered
- Use low-resolution images
- Include misleading content
- Copy competitor designs

## Need help creating images?

**Free tools:**
- Canva (canva.com) - Templates for social media ads
- Figma (figma.com) - Professional design tool
- Photopea (photopea.com) - Free Photoshop alternative

**Tips:**
- Use screenshots from your actual app
- Add a simple background color or gradient
- Include your app icon/logo
- Keep it authentic - don't overpromise
